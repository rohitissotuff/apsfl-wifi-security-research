
# APSFL Wi-Fi Security Research

A Python-based research project investigating predictable password formats and their implications for wireless network security.

## Overview

This project explores a suspected password-generation pattern associated with legacy APSFL Wi-Fi equipment and examines how predictable formats affect password security.

## Contents

- [`RESEARCH.md`](RESEARCH.md): Research background, methodology, calculations, and limitations.
- `generator.py`: Python script demonstrating combinatorial generation.

## Purpose

The goal is to understand password predictability, evaluate the assumptions behind a password format, and promote stronger wireless security practices.
